## Failure and next change

Read-only shape inspection observed seven of eight answer strings were not
literal spans of any retrieved chunk; one was a22-word literal sentence. Several
answers added narration despite the requested short answer. This observation
does not prove the exact semantic cause of every error. The existing runtime
checked JSON, permissions and citation membership, but its free-text answer
contract did not enforce an extractive span or provide an abstention decision.
The87.5% citation coverage alone was therefore inadequate as a success gate.

Next, implement a separately declared short extractive answer contract with
runtime source checks and explicit insufficient-evidence abstention. Corrections
must be new metered model steps; no gold-assisted extraction or score repair.
Keep this failed cohort as development evidence and freeze disjoint public RAG
validation cases after the contract is fixed. Do not silently rerun/overwrite
this directory, change its gate, select only retrieval hits or call it passed.

The stopped native database was copied to an owner-only Mac directory outside
Git:1147 files/43.804MB, archive SHA and every file digest checked.
[Private export receipt](../../ops/reports/agent-rag-private-control-export-2026-10-26.json)
contains no data/credentials. It is a physical PG17 backup whose restore has not
yet been qualified, not Azure Agent persistence or whole-Pod HA. No raw Agent
output, private database archive, executor keys, service environment or weights
were committed to the repository.
